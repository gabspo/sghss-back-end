👥 Tabela: USUARIOS

  • PK id - Identificador único
  • nome - Nome completo
  • UK email - Email único
  • tipo - admin, medico, paciente, secretaria
  • ativo - Status do usuário

🏥 Tabela: PACIENTES

  • PK id - Identificador
  • FK usuario_id - Referência a usuários
  • UK cpf - CPF único
  • data_nascimento - Data de nascimento
  • condicoes_medicas - Histórico
  • alergias - Alergias conhecidas

👨‍⚕️ Tabela: PROFISSIONAIS

  • PK id - Identificador
  • FK usuario_id - Referência a usuários
  • UK crm - CRM único
  • especialidade - Área de atuação
  • horario_inicio/fim - Horário de atendimento

📅 Tabela: CONSULTAS

  • PK id - Identificador
  • FK paciente_id - Referência
  • FK profissional_id - Referência
  • tipo - presencial ou telemedicina
  • status - agendada, realizada, cancelada, nao_compareceu
  • link_video - Para telemedicina

💊 Tabela: MEDICAMENTOS

  • PK id - Identificador
  • nome - Nome do medicamento
  • principio_ativo - Substância ativa
  • dosagem - Dose apresentada
  • estoque - Quantidade em estoque
  • preco - Valor unitário

📋 Tabela: PRESCRICOES

  • PK id - Identificador
  • FK consulta_id - Referência
  • FK medicamento_id - Referência
  • FK profissional_id - Referência
  • dosagem - Como tomar
  • frequencia - Quantas vezes por dia
  • duracao_dias - Duração do tratamento
